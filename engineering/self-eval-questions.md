## Concept Clarifications (WIP)

* ❓ AI vs Machine Learning:

> Artificial Intelligence is the goal:
> making machines intelligent.

> Machine Learning is one way to reach that goal:
> learning patterns from data.

    📌 Example:
    - A chess engine with rules = AI, not ML
    - AlphaZero = AI using ML

* ❓ Software Engineer vs Developer:

> A developer writes code to make things work.
> A software engineer designs systems so they keep working.
