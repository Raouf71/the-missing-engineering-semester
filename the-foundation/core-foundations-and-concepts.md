## 🧠 Core Foundations (Almost everything builds on these)
These are intellectual roots:
* **Mathematics** (Linear algebra, probability, optimization, control theory)
* **Physics** (Mechanics, electromagnetism, thermodynamics)
* **Computer Science (CS)** (Algorithms, data structures, complexity, operating systems, networking, compilers)
> Key idea: CS is about what is computable and how efficiently, not about building products.                                                                                                                                                                   
## 💻 Software & Digital Engineering Fields
1. Software Engineering
    * Designing, building, testing, deploying, and maintaining large, reliable systems
    * Emphasis on:
    * Architecture
    * Scalability
    * Maintainability
    * Collaboration
    * Long-term thinking
    <br>👉 Engineering discipline
2. Software Development
    * Writing code to solve problems or build features
    * Often shorter-term, implementation-focused
    <br>👉 Activity / execution

> Difference (important):<br>
**Software development** = writing code.<br>
**Software engineering** = building systems that survive time, scale, and humans.                

## 📊 Data & Intelligence Fields
1. Data Engineering
    * Pipelines, ETL, data infrastructure
    * Databases, streaming, reliability
    * Makes data usable

2. Data Science
    * Extracting insight from data
    * Statistics, visualization, experimentation
    * Often exploratory                                                                              

## 🤖 AI-Related Fields (Where confusion often happens)
1. Artificial Intelligence (AI) – Umbrella:
    * The goal: machines that exhibit intelligent behavior
    * Includes:
    * Rule-based systems
    * Planning
    * Knowledge representation
    * Search
    * Learning systems
    <br>👉 AI is the vision, not the method.

2. Machine Learning (ML) – Subset of AI:
    * Systems that learn patterns from data
    * Supervised, unsupervised, reinforcement learning
    <br>👉 ML is a tool to achieve AI, not AI itself.

3. Deep Learning:
    * Subset of ML
    * Neural networks with many layers
    * Powers:
    * Vision
    * Speech
    * LLMs
    
4. AI Engineering:
    * Turning ML/LLMs into real products
    * Covers:
    * Model integration
    * APIs
    * RAG systems
    * Monitoring
    * Cost control
    * Reliability
    <br>👉 This is where Generative AI, RAG, Agentic systems live.
