## Technical Skills for Modern Engineers (apply across most fields):

🔑 Core Hard Skills:
* Problem decomposition
* Requirements clarification
* Abstraction
* Debugging mindset → isolate, reproduce, reason
* Reading other people’s code
* Writing clear technical documentation
* Understanding trade-offs (speed vs accuracy, cost vs performance)
* Incremental delivery → MVP → iterate

🔑 Core Soft Skills:
* First-Principles Thinking:
    - Don’t memorize tools
    - Break down complex problems, investigate each subproblem, understand how they link to each other
    > Result: Understanding why things work, not just how

* Learning How to Learn:
    - Tech changes, fundamentals don’t
    - You must:
        - Learn fast
        - Unlearn fast
        - Re-learn better

* Being comfortable with discomfort:
    - all written code has bugs/errors
    - Real problems are poorly defined
    - If you wait for perfect specs, you lose
    - no system is perfect
    > Feeling uncomfortable when not understanding things is not in any sense a sign of weakness. As a matter of fact, it is a biological signal that your brain is primed for growth. By consciously changing your attitude, you change the outcome.

* Communication (Underrated but decisive):
    - Explaining complex ideas simply
    - Writing design docs
    - Accepts feedback without ego
    - Reflects on mistakes
    - Listens and adapts
    > Great engineers reduce confusion, not increase it.

* Thinking Like an Owner: 
    - “If this breaks at 3am, what happens?”
    - “How will someone maintain this in 2 years?”
    > Result: You learn how to build systems while taking into account design requirements/specifications.
